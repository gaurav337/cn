## 1. Packet Tracer UI & Survival Basics

### How to Place Devices
Look at the bottom-left panel of Cisco Packet Tracer:
1. **End Devices** (Laptop icon): Click **PC** or **Laptop**, then click onto the canvas.
2. **Network Devices -> Switches** (Switch icon): Choose **2960** (Standard Layer-2 Switch) or **3560-24PS / 3650-24PS** (Multilayer Layer-3 Switch).
3. **Network Devices -> Routers** (Cylinder icon): Choose **1941**, **2811**, or **2901**.
4. **Connections / Cables** (Lightning bolt icon):
   - **Copper Straight-Through** (Solid black line): Used between *different* devices (PC to Switch, Router to Switch).
   - **Copper Cross-Over** (Dashed black line): Used between *like* devices (Switch to Switch, PC to PC, Router to Router, Router to PC).
   - **Automatically Choose Connection Type** (Orange lightning bolt): If in a hurry, click this, click device 1, then click device 2. It auto-picks the correct cable!

### How to Assign an IP Address to a PC (GUI)
1. Click on the PC in the canvas.
2. Click the **Desktop** tab at the top.
3. Click **IP Configuration**.
4. Select **Static** radio button.
5. Enter:
   - **IPv4 Address**: e.g., `192.168.10.10`
   - **Subnet Mask**: e.g., `255.255.255.0`
   - **Default Gateway**: e.g., `192.168.10.1` (This is the Router/SVI interface IP for this subnet!).
   - **DNS Server**: e.g., `8.8.8.8` (or leave blank if DNS not asked).
6. Close the window. (It saves automatically).

### The Golden Button: Fast Forward Time
* When you connect a switch port, the link light turns **ORANGE** for 30–50 seconds because Spanning Tree Protocol (STP) is listening and learning to prevent loops.
* **Shortcut**: Look at the bottom toolbar near the clock: click the **Fast Forward Time** button (or press `Alt + D`) twice. All lights instantly turn **GREEN**!

## 2. Cisco IOS CLI Modes & Navigation

Click on any Switch or Router, and open the **CLI** tab. Press `Enter` to see the prompt.

| Mode Name | Prompt Looks Like | How to Enter | Purpose / What You Can Do Here |
| :--- | :--- | :--- | :--- |
| **User EXEC Mode** | `Router>` or `Switch>` | Default when you open CLI | View-only mode with very limited commands. |
| **Privileged EXEC Mode** | `Router#` or `Switch#` | Type `enable` (or `en`) | Run `show` verification commands, `ping`, and save configs. |
| **Global Configuration** | `Router(config)#` | Type `configure terminal` (or `conf t`) | Configure device-wide settings, create VLANs, routing protocols. |
| **Interface Config Mode** | `Router(config-if)#` | Type `interface fa0/1` (or `int g0/0`) | Configure IP, switchport mode, duplex, speed on a specific port. |
| **Subinterface Config Mode** | `Router(config-subif)#` | Type `interface g0/0.10` | Used in Router-on-a-stick for 802.1Q VLAN trunking. |
| **VLAN Config Mode** | `Switch(config-vlan)#`| Type `vlan 10` | Name the VLAN. |

### Essential Navigation & Help Commands
* `exit`: Moves back one mode level.
* `end` or `Ctrl + Z`: Jumps straight back to Privileged EXEC mode (`#`).
* `?`: Type `?` anywhere to see all valid commands at this prompt.
* `Tab` key: Auto-completes commands (e.g., typing `conf` and pressing `Tab` types `configure`).
* `write memory` or `wr`: Saves your running configuration to NVRAM so it doesn't get wiped out.

## 3. Master Problem 1: 3 VLANs Across 2 Switches with Trunking
*(Directly tested in MNNIT 2025 Paper Set 1 & Week 10 Assignment Q1)*

### Topology Diagram
```
[PC1: VLAN 10] (Fa0/1) ---\                               /--- (Fa0/1) [PC4: VLAN 10]
[PC2: VLAN 20] (Fa0/2) ---- [ Switch A ] === Trunk === [ Switch B ] ---- (Fa0/2) [PC5: VLAN 20]
[PC3: VLAN 30] (Fa0/3) ---/  (Gig0/1)             (Gig0/1) \--- (Fa0/3) [PC6: VLAN 30]
```

### IP & VLAN Addressing Table
| Device | VLAN | Name | IP Address | Subnet Mask | Connected To Port |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **PC1** | VLAN 10 | CSED | 192.168.10.11 | 255.255.255.0 | Switch A Fa0/1 |
| **PC2** | VLAN 20 | ECE | 192.168.20.11 | 255.255.255.0 | Switch A Fa0/2 |
| **PC3** | VLAN 30 | CIVIL | 192.168.30.11 | 255.255.255.0 | Switch A Fa0/3 |
| **PC4** | VLAN 10 | CSED | 192.168.10.12 | 255.255.255.0 | Switch B Fa0/1 |
| **PC5** | VLAN 20 | ECE | 192.168.20.12 | 255.255.255.0 | Switch B Fa0/2 |
| **PC6** | VLAN 30 | CIVIL | 192.168.30.12 | 255.255.255.0 | Switch B Fa0/3 |
| Trunk Link | All | - | - | - | Switch A Gig0/1 <--> Switch B Gig0/1 |

### Step-by-Step CLI Configuration on Switch A

Open Switch A -> Click **CLI** tab -> Press `Enter`.

```cisco
Switch> enable
Switch# configure terminal
```
> **What it does**: Enters Privileged mode, then Global Configuration mode.  
> **Why**: You cannot make structural configuration changes from user mode.

#### Step 1: Create the 3 VLANs
```cisco
Switch(config)# vlan 10
Switch(config-vlan)# name CSED
Switch(config-vlan)# exit

Switch(config)# vlan 20
Switch(config-vlan)# name ECE
Switch(config-vlan)# exit

Switch(config)# vlan 30
Switch(config-vlan)# name CIVIL
Switch(config-vlan)# exit
```
> **What it does**: Creates VLAN IDs 10, 20, and 30 in the switch database and assigns human-readable names.  
> **Why**: By default, all switch ports belong to VLAN 1. We must explicitly define the VLANs first.

#### Step 2: Assign Switch Ports to the Respective VLANs (Access Mode)
```cisco
Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# no shutdown
Switch(config-if)# exit

Switch(config)# interface FastEthernet0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# no shutdown
Switch(config-if)# exit

Switch(config)# interface FastEthernet0/3
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 30
Switch(config-if)# no shutdown
Switch(config-if)# exit
```
> **What it does**:
> - `switchport mode access`: Declares this port connects to an end-host (PC). It will transmit plain, untagged Ethernet frames.
> - `switchport access vlan X`: Associates this physical port with VLAN number `X`.
> - `no shutdown`: Ensures the port is turned on and active.

#### Step 3: Configure the Inter-Switch Link as a TRUNK Port
```cisco
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# no shutdown
Switch(config-if)# exit
Switch(config)# end
Switch# write memory
```
> **What it does**: Sets port `Gig0/1` to **Trunk** mode.  
> **Why**: An access port can only carry traffic for ONE VLAN. A **Trunk** port carries frames for MULTIPLE VLANs simultaneously across switches using IEEE 802.1Q tags!

### How to Verify Problem 1
Run these commands in Privileged EXEC Mode (`Switch#`):

1. **Verify VLAN Membership**:
   ```cisco
   Switch# show vlan brief
   ```
   *Expected Output*: You will see `10 CSED Fa0/1`, `20 ECE Fa0/2`, `30 CIVIL Fa0/3`. Notice `Gig0/1` is NOT listed here because it is a trunk port!

2. **Verify Trunk Port**:
   ```cisco
   Switch# show interfaces trunk
   ```
   *Expected Output*: Port `Gig0/1`, Mode `on`, Encapsulation `802.1q`, Status `trunking`, VLANs allowed and active: `1,10,20,30`.

3. **Ping Test**:
   - Go to **PC1** -> Desktop -> Command Prompt -> type:
     ```cmd
     ping 192.168.10.12
     ```
     *(Ping to PC4 in same VLAN 10 across the trunk)*: **SUCCESS (Reply received)**!
   - Now type:
     ```cmd
     ping 192.168.20.11
     ```
     *(Ping to PC2 in different VLAN 20)*: **FAILED (Request timed out)**!
     *Why?* Because VLANs isolate broadcast domains. Without a Layer 3 Router or L3 switch, traffic CANNOT pass between different VLANs!

## 4. Master Problem 2: Legacy Inter-VLAN Routing
*(From MNNIT Week 10 Assignment & Senior YouTube Reference)*

### Why is it called "Legacy"?
In the early days of networking, routers did not support virtual subinterfaces on a single cable. To route between 2 VLANs, you had to plug **two physical cables** from the Switch into **two separate physical ports** on the Router!

```
                    +--------------------+
                    |   Cisco Router     |
                    | Fa0/0        Fa0/1 |
                    +---+------------+---+
                        |            |
  Cable for VLAN 10     |            |  Cable for VLAN 20
  (Switchport Fa0/10)   |            |  (Switchport Fa0/11)
                    +---+------------+---+
                    |   Switch 2960      |
                    | Fa0/1        Fa0/2 |
                    +---+------------+---+
                        |            |
                   [PC1: VLAN 10] [PC2: VLAN 20]
```

### CLI Configuration for Legacy Inter-VLAN Routing

#### On Switch (Switch 2960):
Connect PC1 to `Fa0/1`, PC2 to `Fa0/2`.  
Connect Switch `Fa0/10` to Router `Fa0/0` (for VLAN 10).  
Connect Switch `Fa0/11` to Router `Fa0/1` (for VLAN 20).

```cisco
Switch> enable
Switch# configure terminal

! Create VLANs
Switch(config)# vlan 10
Switch(config)# vlan 20

! Assign PC ports
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

Switch(config)# interface fa0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# exit

! Assign Router-Facing Ports as ACCESS ports for each VLAN!
Switch(config)# interface fa0/10
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

Switch(config)# interface fa0/11
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# exit
```
> **Key Viva Point**: In Legacy routing, the router-facing switch ports are configured in **ACCESS** mode, NOT Trunk mode!

#### On Router:
```cisco
Router> enable
Router# configure terminal

! Physical port for VLAN 10
Router(config)# interface fastEthernet 0/0
Router(config-if)# ip address 192.168.10.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit

! Physical port for VLAN 20
Router(config)# interface fastEthernet 0/1
Router(config-if)# ip address 192.168.20.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit
```

#### On PCs:
- **PC1**: IP `192.168.10.10`, Mask `255.255.255.0`, **Default Gateway `192.168.10.1`**
- **PC2**: IP `192.168.20.10`, Mask `255.255.255.0`, **Default Gateway `192.168.20.1`**

#### Verification:
Ping from PC1 (`192.168.10.10`) to PC2 (`192.168.20.10`). Ping succeeds!
*(Drawback: Wastes expensive router interfaces. If you have 50 VLANs, you would need 50 physical router ports!)*

## 5. Master Problem 3: Router-on-a-Stick (ROAS) Inter-VLAN Routing
*(From MNNIT Week 10 Q2 & Week 11 Q2 — High Probability Exam Question)*

### The Architecture
Instead of multiple physical cables, we use **a single physical cable** between the switch and router. That single cable is configured as an 802.1Q **Trunk** link. Inside the router, we divide the physical port (e.g., `Gig0/0`) into logical **subinterfaces** (`Gig0/0.10`, `Gig0/0.20`, `Gig0/0.30`).

```
                    +--------------------+
                    |    Cisco Router    |
                    | Subinterfaces:     |
                    |  .10 -> 192.168.10.1
                    |  .20 -> 192.168.20.1
                    |  .30 -> 192.168.30.1
                    +---------+----------+
                              | Gig0/0 (Single Physical Cable - Trunk)
                              |
                              | Gig0/1 (Trunk)
                    +---------+----------+
                    |    Switch 2960     |
                    | Fa0/1   Fa0/2 Fa0/3|
                    +---+-------+-----+--+
                        |       |     |
                      [PC1]   [PC2]  [PC3]
                     VLAN10  VLAN20 VLAN30
```

---

```cisco
Switch# configure terminal

Switch(config)# vlan 20

Switch(config-vlan)# name OFFICE

! 2. Assign PC Access Ports
Switch(config)# interface FastEthernet0/1

! 3. Make the Router-Facing Port a TRUNK
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# no shutdown
Switch(config-if)# exit
```

---

### Step-by-Step CLI on Router (ROAS Configuration)

Open Router -> CLI -> If asked `"Would you like to enter the initial configuration dialog? [yes/no]:"`, type **`no`** and press `Enter`.

```cisco
Router> enable
Router# configure terminal
```

#### Step 1: Turn On the Physical Interface (DO NOT assign IP here!)
```cisco
Router(config)# interface GigabitEthernet0/0
Router(config-if)# no shutdown
Router(config-if)# exit
```
> **CRITICAL RULE**: Do NOT assign an IP address to `GigabitEthernet0/0`. Just execute `no shutdown` to bring the physical link up!

#### Step 2: Configure Subinterface for VLAN 10
```cisco
Router(config)# interface GigabitEthernet0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit
```
> **ORDER OF COMMANDS IS CRITICAL**:
> You **MUST** type `encapsulation dot1Q 10` **BEFORE** typing `ip address`.  
> If you type `ip address` first, the router will throw an error: *"% Configuring IP routing on a LAN subinterface is only allowed if that subinterface is already configured as part of an 802.10, 802.1Q, or ISL vLAN."*

#### Step 3: Configure Subinterface for VLAN 20
```cisco
Router(config)# interface GigabitEthernet0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit
```

#### Step 4: Configure Subinterface for VLAN 30
```cisco
Router(config)# interface GigabitEthernet0/0.30
Router(config-subif)# encapsulation dot1Q 30
Router(config-subif)# ip address 192.168.30.1 255.255.255.0
Router(config-subif)# exit
Router(config)# end
Router# write memory
```

---

### PC Configuration
- **PC1 (VLAN 10)**: IP `192.168.10.10`, Mask `255.255.255.0`, **Default Gateway `192.168.10.1`**
- **PC2 (VLAN 20)**: IP `192.168.20.10`, Mask `255.255.255.0`, **Default Gateway `192.168.20.1`**
- **PC3 (VLAN 30)**: IP `192.168.30.10`, Mask `255.255.255.0`, **Default Gateway `192.168.30.1`**

### Verification
1. On Router:
   ```cisco
   Router# show ip interface brief
   ```
   *Output*: You will see `GigabitEthernet0/0.10`, `.20`, `.30` all listed as `Status: up, Protocol: up` with their respective IP addresses.
2. From PC1 Command Prompt:
   ```cmd
   ping 192.168.20.10
   ```
   *Result*: First packet might timeout due to ARP; subsequent 3 packets return `Reply from 192.168.20.10: bytes=32 time<1ms TTL=127`. **Inter-VLAN Routing works!**

## 6. Master Problem 4: Multilayer Switch (L3 Switch 3560/3650) Routing via SVIs
*(From MNNIT Week 11 Assignment Q1 & Week 7)*

A Multilayer Switch combines high-speed Layer-2 switching with Layer-3 routing inside the same box using **Switched Virtual Interfaces (SVIs)**.

### Topology
```
           +-----------------------------+
           | Multilayer Switch 3560/3650 |
           | SVI 10: 192.168.10.1        |
           | SVI 20: 192.168.20.1        |
           +--------------+--------------+
                          | Gigabit0/1 (Trunk)
                          |
                          | Gigabit0/1 (Trunk)
           +--------------+--------------+
           |       Access Switch 2960    |
           | Fa0/1                 Fa0/2 |
           +---+---------------------+---+
               |                     |
         [PC1: VLAN 10]        [PC2: VLAN 20]
```

---

### Step-by-Step CLI on Multilayer Switch (3560)

```cisco
Switch> enable
Switch# configure terminal
```

#### Step 1: ENABLE ROUTING (THE MOST IMPORTANT COMMAND!)
```cisco
Switch(config)# ip routing
```
> **WARNING**: A Multilayer switch behaves purely as a Layer 2 switch until you enter `ip routing`! If you forget this command, PCs will NEVER ping across VLANs!

#### Step 2: Create the VLANs
```cisco
Switch(config)# vlan 10
Switch(config)# vlan 20
Switch(config)# exit
```

#### Step 3: Configure SVIs (Virtual Gateway Interfaces for each VLAN)
```cisco
Switch(config)# interface vlan 10
Switch(config-if)# ip address 192.168.10.1 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# exit

Switch(config)# interface vlan 20
Switch(config-if)# ip address 192.168.20.1 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# exit
```

#### Step 4: Configure Trunk Link on Multilayer Switch 3560 (Trap Alert!)
```cisco
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# no shutdown
Switch(config-if)# exit
```
> **EXAM TRAP ON 3560 SWITCH**:
> If you directly type `switchport mode trunk` on a 3560 switch, it will throw:
> *"% Command rejected: An interface whose trunk encapsulation is 'Auto' can not be configured to 'trunk' mode."*  
> You **MUST** run `switchport trunk encapsulation dot1q` first, and then `switchport mode trunk`!

## 8. Master Problem 6: VLSM Design & Configuration
*(From MNNIT 2025 Paper Set 2: "Something related to VLSM")*

### The Problem Statement
You are given the network address **`192.168.1.0/24`**. Design an efficient subnetting scheme for 4 departments using Variable Length Subnet Masking (VLSM):
1. **Department A**: 60 hosts
2. **Department B**: 28 hosts
3. **Department C**: 12 hosts
4. **WAN Link (Router-to-Router)**: 2 hosts

---

### The Golden Rule of VLSM
> **ALWAYS SORT THE SUBNETS IN DESCENDING ORDER OF HOST REQUIREMENTS!**  
> (Largest host requirement first, smallest last).

### Calculation Step-by-Step

#### 1. Department A: 60 Hosts
- Formula: $2^h - 2 \ge 60 \implies 2^6 - 2 = 62 \ge 60$ ($h = 6$ host bits).
- Network bits = $32 - 6 = 26$ bits ($\mathbf{/26}$).
- Subnet Mask: `255.255.255.192` (Binary: `11111111.11111111.11111111.11000000`).
- Block Size: $256 - 192 = 64$.
- **Network ID**: `192.168.1.0/26`
- **Usable Host Range**: `192.168.1.1` to `192.168.1.62`
- **Broadcast ID**: `192.168.1.63`

#### 2. Department B: 28 Hosts
- Formula: $2^h - 2 \ge 28 \implies 2^5 - 2 = 30 \ge 28$ ($h = 5$ host bits).
- Network bits = $32 - 5 = 27$ bits ($\mathbf{/27}$).
- Subnet Mask: `255.255.255.224`.
- Block Size: $256 - 224 = 32$.
- Starts immediately after Dept A:
- **Network ID**: `192.168.1.64/27`
- **Usable Host Range**: `192.168.1.65` to `192.168.1.94`
- **Broadcast ID**: `192.168.1.95`

#### 3. Department C: 12 Hosts
- Formula: $2^h - 2 \ge 12 \implies 2^4 - 2 = 14 \ge 12$ ($h = 4$ host bits).
- Network bits = $32 - 4 = 28$ bits ($\mathbf{/28}$).
- Subnet Mask: `255.255.255.240`.
- Block Size: $256 - 240 = 16$.
- Starts immediately after Dept B:
- **Network ID**: `192.168.1.96/28`
- **Usable Host Range**: `192.168.1.97` to `192.168.1.110`
- **Broadcast ID**: `192.168.1.111`

#### 4. WAN Link: 2 Hosts
- Formula: $2^h - 2 \ge 2 \implies 2^2 - 2 = 2$ ($h = 2$ host bits).
- Network bits = $32 - 2 = 30$ bits ($\mathbf{/30}$).
- Subnet Mask: `255.255.255.252`.
- Block Size: $256 - 252 = 4$.
- Starts immediately after Dept C:
- **Network ID**: `192.168.1.112/30`
- **Usable Host Range**: `192.168.1.113` to `192.168.1.114`
- **Broadcast ID**: `192.168.1.115`

---

### Step-by-Step Simulation Mode Analysis (How to Demonstrate to the Examiner)

#### Experiment 1: The Switch with Empty CAM Table (Unknown Unicast Flooding)
1. Clear the switch dynamic MAC table in CLI:
   ```cisco
   Switch# clear mac-address-table dynamic
   Switch# show mac-address-table
   ```
   *(Notice: Table is empty! Only CPU/multicast management entries exist).*
2. Switch Packet Tracer to **Simulation Mode** (bottom right, click the stopwatch icon, or press `Shift + S`).
3. Set filter to show only `ICMP` and `ARP`.
4. On **PC0**, open Command Prompt and run: `ping 192.168.1.2`.
5. Click **Capture / Forward** step-by-step:
   - **Step 1 (Source Learning)**: The frame arrives at Switch0 on `Fa0/1`. The switch immediately reads the **Source MAC Address** from the frame header and records:
     `VLAN 1 | 0001.96XX.XXXX | DYNAMIC | FastEthernet0/1`
   - **Step 2 (Lookup Miss & Flooding)**: The switch looks up the **Destination MAC** (`PC1`). Because the table was cleared, it is NOT found. The switch performs **Unknown Unicast Flooding**: it sends a duplicate copy of the frame out of EVERY active port in VLAN 1 *except* the ingress port (`Fa0/2` and `Fa0/3`).
   - **Step 3 (Host NIC Discard)**: PC2 receives the frame on `Fa0/3`, compares the destination MAC to its own NIC MAC, detects a mismatch, and drops the frame (**red cross appears in Packet Tracer**).
   - **Step 4 (Target Reply & Learning)**: PC1 matches the destination MAC, processes the packet, and transmits an ICMP Echo Reply back to Switch0 on `Fa0/2`.
   - **Step 5 (Unicast Forwarding)**: The switch learns PC1's MAC address on `Fa0/2`. Now, looking up the destination MAC (PC0), it finds `Fa0/1` in its table. It forwards the reply **ONLY** to `Fa0/1`. PC2 receives nothing!

#### Experiment 2: The Switch with Populated CAM Table (Pure Unicast Forwarding)
1. Click **Reset Simulation** (do NOT clear the MAC table).
2. Send `ping 192.168.1.2` again from PC0.
3. Advance simulation step-by-step:
   - Frame leaves PC0 $
ightarrow$ enters Switch0 `Fa0/1`.
   - Destination lookup hits `Fa0/2` immediately.
   - Frame is forwarded **only** to PC1.
   - **Zero frames appear on Fa0/3; zero red crosses anywhere!**
   - **Performance proof**: In real time, the first ping RTT is ~35 ms due to ARP and flooding; subsequent pings drop to $<1$ ms!

#### Experiment 3: The Hub (Perpetual Flooding & Collision Domain)
1. In Simulation mode, send a ping from **PC3** to **PC4** on the Hub.
2. Advance simulation:
   - Hub receives electrical signal on Port0 and **blindly broadcasts / repeats it out of Port1 and Port2 simultaneously**.
   - PC5 receives the frame, drops it with a red cross.
   - When PC4 replies, the Hub floods the reply out of Port0 and Port2 again!
   - **Crucial Viva Distinction**:
     - A switch floods *temporarily* as a fallback when an address is unknown, then converges to pure point-to-point forwarding.
     - A hub floods *permanently for every frame* because it lacks memory, CPU, and MAC address intelligence.

## 12. Master Problem 10: Dynamic Routing with RIP (Routing Information Protocol)

### Routing Information Protocol (RIPv2) Key Properties
- **Algorithm**: Distance Vector (Bellman-Ford algorithm).
- **Metric**: Hop count (1 router hop = cost 1).
- **Maximum Valid Metric**: **15 hops** (Hop 16 = Metric Infinity / Unreachable network).
- **Administrative Distance (AD)**: **120** (Higher than Static Route = 1, OSPF = 110, Connected = 0).
- **Update Frequency**: Every **30 seconds** (Periodic broadcast in RIPv1; Multicast to `224.0.0.9` in RIPv2).
- **Loop Prevention Mechanisms**: Split Horizon, Poison Reverse, Triggered Updates, Holddown Timers (180s).

### Comparative Analysis: Multilayer Switch vs Router-on-a-Stick (ROAS)
*(Tested in Week 11 Assignment Task 2)*

| Parameter | Multilayer Switch (SVI Method) | Router-on-a-Stick (ROAS) |
| :--- | :--- | :--- |
| **Physical Topology** | Single L3 switch connects to access switches via trunk links. | Router connects to L2 switch via a single physical trunk link. |
| **Packet Path (Simulation)** | Frame enters MLS $
ightarrow$ routed internally via ASIC backplane $
ightarrow$ egresses switchport directly. | Frame travels up the trunk to router $
ightarrow$ routed in software $
ightarrow$ hairpin turns back down the *same* physical link! |
| **Bandwidth Bottleneck** | None (Multi-gigabit non-blocking switching bus). | Severe trunk bottleneck ("hairpin / one-armed router" problem). |
| **Routing Mechanism** | Hardware CEF (Cisco Express Forwarding) in ASICs. | Software CPU-based packet forwarding. |
| **Configuration Command** | `interface vlan <id>` + `ip routing` | `interface g0/0.<id>` + `encapsulation dot1Q <id>` |
| **`show ip route` Output** | Shows SVIs as directly connected: `C 192.168.10.0/24 is directly connected, Vlan10` | Shows subinterfaces: `C 192.168.10.0/24 is directly connected, GigabitEthernet0/0.10` |

The UDP Client sends a string (1 to 32 bytes) provided as command-line argument. The UDP Server receives it and echoes it back.

#### 1. UDP Server (`20243104_EchoServer.c`):
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

#define PORT 8888
#define BUFFER_SIZE 1024

int main() {
    int sockfd;
    char buffer[BUFFER_SIZE];
    struct sockaddr_in servaddr, cliaddr;
    socklen_t len = sizeof(cliaddr);

    // 1. Create UDP datagram socket
    if ((sockfd = socket(AF_INET, SOCK_DGRAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    memset(&servaddr, 0, sizeof(servaddr));
    servaddr.sin_family = AF_INET;
    servaddr.sin_addr.s_addr = INADDR_ANY;
    servaddr.sin_port = htons(PORT);

    // 2. Bind socket to local port
    if (bind(sockfd, (const struct sockaddr *)&servaddr, sizeof(servaddr)) < 0) {
        perror("Bind failed");
        close(sockfd);
        exit(EXIT_FAILURE);
    }

    printf("Server started ... waiting for connection ...\n");

    while (1) {
        memset(buffer, 0, BUFFER_SIZE);
        // 3. Receive datagram from client
        ssize_t n = recvfrom(sockfd, buffer, BUFFER_SIZE - 1, 0,
                             (struct sockaddr *)&cliaddr, &len);
        if (n < 0) {
            perror("recvfrom error");
            continue;
        }
        buffer[n] = '\0';
        printf("Received %zd bytes from %s:%d: %s\n", n,
               inet_ntoa(cliaddr.sin_addr), ntohs(cliaddr.sin_port), buffer);

        // 4. Echo datagram back to client
        sendto(sockfd, buffer, n, 0, (const struct sockaddr *)&cliaddr, len);
    }

    close(sockfd);
    return 0;
}
```

#### 1. TCP String Reversal Server (`ReverseServerTCP.c`):
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

#define PORT 9999
#define BUFFER_SIZE 1024

void reverse_string(char *str) {
    int i = 0, j = strlen(str) - 1;
    while (i < j) {
        char temp = str[i];
        str[i] = str[j];
        str[j] = temp;
        i++;
        j--;
    }
}

int main() {
    int listen_fd, conn_fd;
    struct sockaddr_in servaddr, cliaddr;
    socklen_t cli_len = sizeof(cliaddr);
    char buffer[BUFFER_SIZE];

    if ((listen_fd = socket(AF_INET, SOCK_STREAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    int opt = 1;
    setsockopt(listen_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    memset(&servaddr, 0, sizeof(servaddr));
    servaddr.sin_family = AF_INET;
    servaddr.sin_addr.s_addr = INADDR_ANY;
    servaddr.sin_port = htons(PORT);

    if (bind(listen_fd, (struct sockaddr *)&servaddr, sizeof(servaddr)) < 0) {
        perror("Bind failed");
        exit(EXIT_FAILURE);
    }

    if (listen(listen_fd, 5) < 0) {
        perror("Listen failed");
        exit(EXIT_FAILURE);
    }

    printf("String Reversal Server listening on port %d ...\n", PORT);

    while (1) {
        conn_fd = accept(listen_fd, (struct sockaddr *)&cliaddr, &cli_len);
        if (conn_fd < 0) {
            perror("Accept error");
            continue;
        }
        printf("Connected to client: %s:%d\n", inet_ntoa(cliaddr.sin_addr), ntohs(cliaddr.sin_port));

        while (1) {
            memset(buffer, 0, BUFFER_SIZE);
            ssize_t bytes_read = recv(conn_fd, buffer, BUFFER_SIZE - 1, 0);
            if (bytes_read <= 0) {
                printf("Client disconnected.\n");
                break;
            }
            // Strip trailing newline if present
            buffer[strcspn(buffer, "\r\n")] = '\0';
            printf("Server Received: [%s]\n", buffer);

            reverse_string(buffer);
            printf("Server Sending Reversed: [%s]\n", buffer);

    return 0;
}
```

```c
int calculate(double op1, char operator, double op2, double *res) {
```

```c
        perror("Connect failed");
        exit(EXIT_FAILURE);
    }

    printf("Connected to Calculator Server successfully!\n");
    printf("Enter expression (e.g. 10.5 + 4) or 'quit' to exit:\n");

    char send_buf[BUFFER_SIZE], recv_buf[BUFFER_SIZE];
    while (1) {
        printf("Calc > ");
        if (!fgets(send_buf, BUFFER_SIZE, stdin)) break;
        send_buf[strcspn(send_buf, "\r\n")] = '\0';

        // Send expression to server
        send(sockfd, send_buf, strlen(send_buf), 0);

        if (strcmp(send_buf, "quit") == 0) {
            printf("Quitting... Connection closed.\n");
            break;
        }

        memset(recv_buf, 0, BUFFER_SIZE);
        ssize_t n = recv(sockfd, recv_buf, BUFFER_SIZE - 1, 0);
        if (n <= 0) {
            printf("Server closed connection.\n");
            break;
        }
        recv_buf[n] = '\0';
        printf("%s", recv_buf);
    }

    close(sockfd);
    return 0;
}
```

- **Command**:
  ```cisco
  Switch# show spanning-tree
  ```
- **How to Identify Root Bridge**:
  - Inspect the output on each switch. Look for the phrase:
    `This bridge is the root`
  - The Root Bridge is elected based on the lowest **Bridge ID (BID)**:
    $$\text{BID} = \text{Priority (Default 32768)} + \text{Sys-id-ext (VLAN 1)} + \text{Base MAC Address}$$
  - The switch with the mathematically lowest MAC address wins the election (`Switch0`).

##### Q9. Identify which port among the three switches is in Blocking state and which ports are Forwarding.
- **Root Bridge (`Switch0`)**: All ports are **Designated Ports** in **Forwarding (FWD)** state.
- **Non-Root Switches (`Switch1`, `Switch2`)**: Each elects one **Root Port (FWD)** facing the Root Bridge with lowest path cost (Cost 19 for 100 Mbps FastEthernet).
- **Alternate / Blocked Port**:
  - On `Switch2`, interface `FastEthernet0/20` is assigned role **Alternate (Altn)** and state **BLOCKING (BLK)**.
  - In Packet Tracer, its link LED is **AMBER** to prevent Layer-2 broadcast storms and loop loops.

  - Network reachability is automatically restored through `Switch1`!

- **Switch Case**: Each PC connected to a separate switch port forms an **independent micro-segmented collision domain** running in full-duplex with zero collisions.

### Assignment Week 9: Dynamic Routing with RIP (Routing Information Protocol)

#### Architectural Concepts of RIPv2
- **Protocol Type**: Distance Vector routing protocol (RFC 2453).
- **Metric**: Hop count (Maximum valid hops = 15; 16 hops = Infinity / Unreachable).
- **Administrative Distance**: `120`.
- **Timer Defaults**: Periodic Update = 30 seconds; Invalid Timer = 180s; Flush Timer = 240s.
- **Multicast Address**: RIPv2 multicasts routing table updates to `224.0.0.9` (UDP port 520).
- **Subnet Support**: Classless Routing (CIDR/VLSM) supported when `version 2` and `no auto-summary` are configured!

#### Program 1: UDP Echo Server & Echo Client in C

##### A. Server Source Code (`20243104_EchoServer.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define PORT 8888
#define BUFFER_SIZE 64

int main() {
    int server_fd;
    char buffer[BUFFER_SIZE];
    struct sockaddr_in server_addr, client_addr;
    socklen_t client_len = sizeof(client_addr);

    // 1. Create UDP datagram socket
    if ((server_fd = socket(AF_INET, SOCK_DGRAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    // 2. Configure server address structure
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY; // Bind to all local interfaces
    server_addr.sin_port = htons(PORT);

    // 3. Bind socket to IP address and port
    if (bind(server_fd, (const struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("Bind failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    printf("Server started ... waiting for connection on port %d ...\n", PORT);

    // 4. Receive datagram from client
    int bytes_received = recvfrom(server_fd, buffer, BUFFER_SIZE - 1, 0,
                                  (struct sockaddr *)&client_addr, &client_len);
    if (bytes_received < 0) {
        perror("recvfrom failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }
    buffer[bytes_received] = '\0';

    printf("Received from client [%s:%d]: %s\n",
           inet_ntoa(client_addr.sin_addr), ntohs(client_addr.sin_port), buffer);

    // 5. Echo received string back to client
    printf("Sending back to client: %s\n", buffer);
    sendto(server_fd, buffer, bytes_received, 0,
           (const struct sockaddr *)&client_addr, client_len);

    // 6. Disconnect and terminate
    printf("Server finished echoing. Terminating.\n");
    close(server_fd);
    return 0;
}
```

##### B. Client Source Code (`20243104_EchoClient.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define PORT 8888
#define BUFFER_SIZE 64

int main(int argc, char *argv[]) {
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <Server_IP> \"<string_to_echo>\"\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    char *server_ip = argv[1];
    char *message = argv[2];
    size_t msg_len = strlen(message);

    // Validate string length (1 to 32 bytes inclusive)
    if (msg_len < 1 || msg_len > 32) {
        fprintf(stderr, "Error: Input string length must be between 1 and 32 bytes (Length provided: %zu bytes).\n", msg_len);
        exit(EXIT_FAILURE);
    }

    int client_fd;
    char buffer[BUFFER_SIZE];
    struct sockaddr_in server_addr;

    // 1. Create UDP socket
    if ((client_fd = socket(AF_INET, SOCK_DGRAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(PORT);
    if (inet_pton(AF_INET, server_ip, &server_addr.sin_addr) <= 0) {
        perror("Invalid server IP address");
        close(client_fd);
        exit(EXIT_FAILURE);
    }

    // 2. Send string to server
    sendto(client_fd, message, msg_len, 0,
           (const struct sockaddr *)&server_addr, sizeof(server_addr));

    // 3. Receive echoed string back
    socklen_t addr_len = sizeof(server_addr);
    int bytes_received = recvfrom(client_fd, buffer, BUFFER_SIZE - 1, 0,
                                  (struct sockaddr *)&server_addr, &addr_len);
    if (bytes_received < 0) {
        perror("recvfrom failed");
        close(client_fd);
        exit(EXIT_FAILURE);
    }
    buffer[bytes_received] = '\0';

    printf("Received from server: %s\n", buffer);

    close(client_fd);
    return 0;
}
```

##### A. Server Source Code (`TimeOfDayServer.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <time.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define BUFFER_SIZE 128

int main(int argc, char *argv[]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <Port>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    int port = atoi(argv[1]);

    int sockfd;
    char buffer[BUFFER_SIZE];
    struct sockaddr_in server_addr, client_addr;
    socklen_t client_len = sizeof(client_addr);

    if ((sockfd = socket(AF_INET, SOCK_DGRAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(port);

    if (bind(sockfd, (const struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("Bind failed");
        close(sockfd);
        exit(EXIT_FAILURE);
    }

    printf("[Time Server] Listening on UDP port %d ...\n", port);

    while (1) {
        int n = recvfrom(sockfd, buffer, BUFFER_SIZE - 1, 0,
                         (struct sockaddr *)&client_addr, &client_len);
        if (n < 0) continue;
        buffer[n] = '\0';

        printf("[Time Server] Received request from %s:%d: \"%s\"\n",
               inet_ntoa(client_addr.sin_addr), ntohs(client_addr.sin_port), buffer);

        // Fetch current system time
        time_t raw_time;
        time(&raw_time);
        char *time_str = ctime(&raw_time);
        time_str[strcspn(time_str, "\n")] = 0; // Strip trailing newline

        printf("[Time Server] Responding with current time: %s\n", time_str);
        sendto(sockfd, time_str, strlen(time_str), 0,
               (struct sockaddr *)&client_addr, client_len);
    }

    close(sockfd);
    return 0;
}
```

#### Program 1: String Reversal Server & Client using TCP

##### A. Server Source Code (`StringReverseServerTCP.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define PORT 9999
#define BUFFER_SIZE 256

void reverse_string(char *str) {
    int i = 0, j = strlen(str) - 1;
    while (i < j) {
        char temp = str[i];
        str[i] = str[j];
        str[j] = temp;
        i++;
        j--;
    }
}

int main() {
    int server_fd, client_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t client_len = sizeof(client_addr);
    char buffer[BUFFER_SIZE];

    if ((server_fd = socket(AF_INET, SOCK_STREAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(PORT);

    if (bind(server_fd, (struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("Bind failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    if (listen(server_fd, 5) < 0) {
        perror("Listen failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    printf("[TCP Reversal Server] Listening on port %d ...\n", PORT);

    while (1) {
        client_fd = accept(server_fd, (struct sockaddr *)&client_addr, &client_len);
        if (client_fd < 0) {
            perror("Accept failed");
            continue;
        }

        printf("\n[Server] Client connected: %s:%d\n",
               inet_ntoa(client_addr.sin_addr), ntohs(client_addr.sin_port));

        while (1) {
            memset(buffer, 0, BUFFER_SIZE);
            int bytes_read = recv(client_fd, buffer, BUFFER_SIZE - 1, 0);
            if (bytes_read <= 0) {
                printf("[Server] Client disconnected.\n");
                break;
            }
            buffer[bytes_read] = '\0';
            buffer[strcspn(buffer, "\r\n")] = 0; // Strip newline

            printf("[Server] Received from client: \"%s\"\n", buffer);

            reverse_string(buffer);

            printf("[Server] Sending reversed string: \"%s\"\n", buffer);
            send(client_fd, buffer, strlen(buffer), 0);
        }
        close(client_fd);
    }

    close(server_fd);
    return 0;
}
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <math.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define BUFFER_SIZE 256

int main(int argc, char *argv[]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <Port>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    int port = atoi(argv[1]);

    int server_fd, client_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t client_len = sizeof(client_addr);
    char buffer[BUFFER_SIZE];

    if ((server_fd = socket(AF_INET, SOCK_STREAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(port);

    if (bind(server_fd, (struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("Bind failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    if (listen(server_fd, 5) < 0) {
        perror("Listen failed");
        close(server_fd);
        exit(EXIT_FAILURE);
    }

    printf("Server listening on port %d\n", port);

    while (1) {
        client_fd = accept(server_fd, (struct sockaddr *)&client_addr, &client_len);
        if (client_fd < 0) continue;

        printf("Client %s on port %d connected\n",
               inet_ntoa(client_addr.sin_addr), ntohs(client_addr.sin_port));

        while (1) {
            memset(buffer, 0, BUFFER_SIZE);
            int n = recv(client_fd, buffer, BUFFER_SIZE - 1, 0);
            if (n <= 0) {
                printf("Client closed connection\n");
                printf("Server listening on port %d\n", port);
                break;
            }
            buffer[n] = '\0';
            buffer[strcspn(buffer, "\r\n")] = 0;

            if (strcmp(buffer, "-1") == 0) {
                printf("Client closed connection\n");
                printf("Server listening on port %d\n", port);
                break;
            }

            printf("Received from client: %s\n", buffer);

            // Parse expression: operand1 operator operand2
            double op1, op2, result = 0.0;
            char op;
            char reply[BUFFER_SIZE];

            if (sscanf(buffer, "%lf %c %lf", &op1, &op, &op2) == 3) {
                int valid = 1;
                switch (op) {
                    case '+': result = op1 + op2; break;
                    case '-': result = op1 - op2; break;
                    case '*': result = op1 * op2; break;
                    case '/': 
                        if (op2 == 0) {
                            strcpy(reply, "Error: Division by zero");
                            valid = 0;
                        } else {
                            result = op1 / op2;
                        }
                        break;
                    case '^': result = pow(op1, op2); break;
                    default:
                        strcpy(reply, "Error: Invalid operator (+, -, *, /, ^)");
                        valid = 0;
                }
                if (valid) {
                    snprintf(reply, BUFFER_SIZE, "%g", result);
                }
            } else {
                strcpy(reply, "Error: Malformed expression format (e.g., 3.5 * -4)");
            }

            printf("Sending to client: %s\n", reply);
            send(client_fd, reply, strlen(reply), 0);
        }
        close(client_fd);
    }

    close(server_fd);
    return 0;
}
```

##### B. Client Source Code (`CalcClientTCP.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <netdb.h>
#include <arpa/inet.h>
#include <sys/socket.h>

#define BUFFER_SIZE 256

int main(int argc, char *argv[]) {
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <Hostname_or_IP> <Port>\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    char *hostname = argv[1];
    int port = atoi(argv[2]);

    // 1. Resolve hostname into IP address
    struct hostent *he = gethostbyname(hostname);
    if (he == NULL) {
        herror("gethostbyname failed");
        exit(EXIT_FAILURE);
    }
    char *ip_str = inet_ntoa(*(struct in_addr *)he->h_addr_list[0]);

    // 2. Create TCP socket
    int sockfd;
    if ((sockfd = socket(AF_INET, SOCK_STREAM, 0)) < 0) {
        perror("Socket creation failed");
        exit(EXIT_FAILURE);
    }

    struct sockaddr_in server_addr;
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(port);
    server_addr.sin_addr = *(struct in_addr *)he->h_addr_list[0];

    // 3. Connect to server
    if (connect(sockfd, (struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("Connection failed");
        close(sockfd);
        exit(EXIT_FAILURE);
    }

    printf("TCP client connected to %s on port %d\n", ip_str, port);

    char send_buf[BUFFER_SIZE];
    char recv_buf[BUFFER_SIZE];

    while (1) {
        printf("\nEnter an expression in the following format:\n");
        printf("operand1 operator operand2  Valid operators are + - * / ^. To quit, enter -1.\n");
        printf("Client> ");
        if (!fgets(send_buf, BUFFER_SIZE, stdin)) break;
        send_buf[strcspn(send_buf, "\r\n")] = 0;

        if (strcmp(send_buf, "-1") == 0) {
            send(sockfd, "-1", 2, 0);
            printf("Bye!\n");
            break;
        }
        if (strlen(send_buf) == 0) continue;

        send(sockfd, send_buf, strlen(send_buf), 0);

        memset(recv_buf, 0, BUFFER_SIZE);
        int n = recv(sockfd, recv_buf, BUFFER_SIZE - 1, 0);
        if (n <= 0) {
            printf("Server disconnected.\n");
            break;
        }
        recv_buf[n] = '\0';

        printf("ANS: %s = %s\n", send_buf, recv_buf);
    }

    close(sockfd);
    return 0;
}
```

## 17. Golden Troubleshooting Rules for the Exam


| Symptom | Root Cause | Instant Fix |
| :--- | :--- | :--- |
| **Ping fails on the 1st packet** (`Request timed out`, then 3 replies succeed) | Normal behavior! ARP table is being resolved for the first packet. | Ping a second time. It will be 100% success (`4/4`). |
| **Link light stays orange** | STP (Spanning Tree) 30s listening/learning. | Click **Fast Forward Time** (`>>`) button twice. |
| **Router link lights are RED** | Cisco router ports are `administratively down` by default. | Enter interface mode on router and type `no shutdown`. |
| **PCs in different VLANs cannot ping** | Missing Default Gateway on PC, or forgot `ip routing` on L3 switch, or router subinterface encapsulation not set. | 1. Check PC Gateway points to router subinterface IP.<br>2. On L3 switch, type `ip routing`.<br>3. Check trunk link: `show interfaces trunk`. |
| **Router error: "% Subinterface is only allowed if configured with 802.1Q"** | You typed `ip address` before `encapsulation dot1Q`. | Type `encapsulation dot1Q <vlan_id>` first, THEN `ip address <ip> <mask>`. |
| **3560 Switch rejects `switchport mode trunk`** | Default encapsulation is 'auto'. | Type `switchport trunk encapsulation dot1q` first, then `switchport mode trunk`. |
